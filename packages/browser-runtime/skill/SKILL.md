# Browser Runtime (`browser-runtime`)

Provides shared graphical, typography, and audio runtime libraries required to run headless Chromium, Playwright, Puppeteer, and Electron applications.

## Constituent Libraries
- `cairo` and `pango`: Typography and vector rendering libraries.
- `mesa-libgbm`: Generic buffer management for graphics hardware acceleration and software rendering.
- `nss` and `nspr`: Network security services and Netscape portable runtime.
- `libX11` and X extensions: X11 protocol client libraries for headless windowing.
- `alsa-lib`: Audio architecture runtime for media rendering.
