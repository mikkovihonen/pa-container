## Optional Feature: TypeScript / JavaScript Language Server (`typescript`)

Provides Language Server Protocol implementation for TypeScript and JavaScript using `typescript-language-server`.

### Capabilities
- Intelligent code completion, hover, and parameter information.
- Navigation to definitions, implementations, and type definitions.
- Refactoring operations, code actions, and rename support.

### Usage
- Binary: `/usr/local/bin/typescript-language-server`
- Check version: `typescript-language-server --version`
- Direct stdio invocation: `typescript-language-server --stdio`
