## Optional Feature: Rust Language Server (`rust-analyzer`)

Provides modular compiler frontend and LSP implementation for Rust codebases.

### Capabilities
- Semantic code navigation (goto definition, find references, type definitions).
- Inlay hints, signature help, and inline diagnostics.
- Workspace symbols and full symbol search.

### Usage
- Binary: `/usr/local/bin/rust-analyzer`
- Check version: `rust-analyzer --version`
- Run analysis check: `rust-analyzer analysis-stats .`
