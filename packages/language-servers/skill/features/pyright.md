## Optional Feature: Python Language Server (`pyright`)

Provides fast static type checking and Language Server Protocol services for Python.

### Capabilities
- Type inference, type checking, and strict typing validations.
- Jump to definition, signature help, find references, and symbol renaming.
- Multi-root workspace and virtual environment support.

### Usage
- Binary: `/usr/local/bin/pyright`
- Check version: `pyright --version`
- Run static type checker: `pyright .`
