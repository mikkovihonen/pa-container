# T3 Code Integration

## Overview

T3 Code provides a browser-based multi-agent IDE interface connecting coding agents (Pi, Claude Code, OpenCode, Google Antigravity).

## Common Usage

Serve T3 Code:
```bash
t3 serve --host 0.0.0.0 --port 3773
```
