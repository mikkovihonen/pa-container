## Ghidra Interactive GUI

The full Ghidra interactive GUI application is integrated with the virtual desktop.

### Starting Ghidra GUI

1. Ensure the `virtual-desktop` package is active.
2. Launch Ghidra inside the desktop environment:
    ```bash
    ghidra &
    ```
3. Connect via the noVNC browser interface (`pa desktop`) or VNC client (port 5900) to interact with the CodeBrowser, Program Tree, and Symbol Tree.
