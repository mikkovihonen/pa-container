# Browser Automation (`browser`)

Selectable browser capability features for web browser automation, page rendering, DOM inspection, and structured MCP-based browser control.

## Available Features
- `chromium`: Chrome for Testing browser engine, `google-chrome` symlink, and the Playwright MCP server, with interactive GUI use on the virtual desktop.
- `chromium-headless`: Shared runtime libraries that headless Chromium, Playwright, and Puppeteer need.
