## Optional Feature: Zig Language Server (`zls`)

Provides completion, definition lookup, diagnostics, and hover hints for Zig projects.

### Capabilities
- Autocompletion and type information for Zig standard library and workspace packages.
- Goto definition and find references across Zig modules.

### Usage
- Binary: `/usr/local/bin/zls`
- Check version: `zls --version`
- Configure in project: Place `zls.json` in workspace root if custom options are required.
